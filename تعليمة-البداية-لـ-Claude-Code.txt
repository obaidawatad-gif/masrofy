أبي تبني لي تطبيق Android حقيقي بلغة Kotlin و Jetpack Compose لإدارة المصاريف الشخصية.

الاسم: مصاريفي

المزايا الأساسية المطلوبة (ابدأ بأبسط نسخة تشتغل - MVP - ثم نضيف الباقي تدريجياً):

1. شاشة رئيسية تعرض:
   - الدخل الشهري (راتب ثابت + دخل إضافي يُدخل يدوياً)
   - المتبقي بعد المصاريف (يتناقص تلقائياً مع كل مصروف)
   - قائمة "آخر المصاريف" مع تاريخ كل مصروف

2. إدخال مصروف بثلاث طرق:
   - زر "إضافة يدوية": نموذج بسيط (الاسم، المبلغ، الفئة، مكان الصرف اختياري)
   - زر "تصوير فاتورة": يفتح الكاميرا (لاحقاً نضيف قراءة تلقائية OCR بـ ML Kit)
   - زر "تسجيل صوتي": يسجل ملاحظة صوتية ويحفظها كملف مرفق بالمصروف

3. فئات المصاريف: منزلي، مواصلات، كهرباء، صيانة، إيجار، أخرى

4. مصاريف ثابتة شهرية (إيجار، فواتير) مع تذكير عند التأخر بالدفع

5. تخزين كل البيانات محلياً على الجهاز باستخدام Room (قاعدة بيانات SQLite)

المرحلة الأولى (ابدأ فيها الآن فقط):
- أنشئ هيكل المشروع الكامل (build.gradle, MainActivity, بنية المجلدات)
- اعمل الشاشة الرئيسية بواجهة Jetpack Compose بسيطة تدعم اللغة العربية (RTL)
- اعمل قاعدة بيانات Room بسيطة لحفظ المصاريف (الاسم، المبلغ، الفئة، التاريخ)
- زر "إضافة يدوية" يشتغل فعلياً ويحفظ في قاعدة البيانات

بعد ما تخلص هذي المرحلة، ابنِ المشروع وشغّله على المحاكي (emulator) للتأكد إنه يشتغل فعلياً بدون أخطاء قبل ما تخبرني إنك خلصت.
